# JUC 教程索引

本模块把背景知识集中在 `docs` 中，练习类只保留课程目标和 TODO。

推荐阅读顺序：

1. [学习地图](../LEARNING_MAP.md)：先建立课程全貌。
2. [JUC 并发与高并发实战指南](JUC_CONCURRENCY_GUIDE.md)：按 Lab 阅读背景、API 参数和代码例子。
3. 完成 `exercises` 中对应练习。
4. 卡住后查看 `docs/hints/lab-XX.md`。
5. 最后才对照 `answers`。

教程中的方案以 Java 8、单 JVM 为基础。涉及数据库、Redis、消息队列和分布式锁的内容用于说明边界，不要求本模块安装外部中间件。
